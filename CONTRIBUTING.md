# Contributing

Run the standard checks before opening a change:

```text
python -m unittest discover -s tests -v
git diff --check
```

Keep the deterministic scanner usable without a network, account, API key, or
hosted service. New evidence fields must preserve commit/file
provenance, and generated laws remain candidates until a separate review store
records a decision.

Behavior changes need focused regression tests and a concise change note. Do not edit source repositories, generate policy files,
or publish external artifacts as part of a normal contribution.
