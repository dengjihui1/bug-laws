# Real-repository validation

These reports were generated by Bug Laws 0.1 against public Python repositories.

- `projectmem-report/`: 21 commits, 4 fix candidates, 3 candidate laws.
- `click-report/`: 807 commits from five years, 80 fix candidates inspected, 28 candidate laws.

They are evidence samples, not endorsements by either project's maintainers. Candidate laws remain machine-recovered suggestions that require human review.

Reproduce with:

```text
buglaws scan /path/to/projectmem --output demo/projectmem-report --label github.com/riponcm/projectmem
buglaws scan /path/to/click --output demo/click-report --label github.com/pallets/click --since "5 years ago" --limit 80
```
